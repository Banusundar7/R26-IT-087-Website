PomeGuard - Research Project Website (HTML + CSS only)
=======================================================

FOLDER STRUCTURE
  index.html              -> the whole website (Home, Domain, Milestones, Documents, Presentations, About Us, Contact Us)
  css/style.css           -> all styling
  assets/images/          -> logo, hero picture, team photos
  assets/documents/       -> put your PDF documents here
  assets/slides/          -> put your presentation PDF / PPTX here

WHAT TO EDIT
1. Team photos: replace member1.svg ... member4.svg, supervisor.svg, co_supervisor.svg
   with real photos. Easiest: save as member1.jpg etc. and change the file name in index.html
   (search for "member1.svg"). Square photos (e.g. 400x400) look best.
2. Names, IT numbers, emails: search "Member 1 Name", "IT2XXXXXXX", "Supervisor Name" in index.html.
3. Project name / text: "PomeGuard" is a suggested name - change it if your project has another name.
   Update Literature survey, Research gap, Problem, Objectives, Components to match your proposal.
4. Milestones: update dates and marks with your module's official marking scheme.
5. Documents & slides: copy files into assets/documents and assets/slides using the SAME
   file names as in index.html (e.g. Project_Charter.pdf), or change the links.
   For a pending item that becomes available, change <div class="doc is-pending"> to an
   <a class="doc" href="..."> like the others.
6. Contact: phone numbers and group email in the Contact Us section.

UPLOAD
  Course limit is 20 MB. Compress photos (use JPG, ~100-200 KB each) and PDFs if needed.
  Upload the whole folder keeping the same structure; index.html is the start page.
